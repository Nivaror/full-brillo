# FULL BRILLO

Demo de la tienda de detailing automotor. Abrí `index.html` en un navegador. Funciona con el archivo descargado y no requiere instalación ni un servidor.

## Recorrido de prueba

1. Filtrá el catálogo o entrá a Mayoristas. Agregá 6 o 12 unidades de una misma presentación para ver los tramos de descuento.
2. Abrí el carrito y cotizá con un código postal de prueba, por ejemplo `1425`, `2000` o `C1425ABC`.
3. Elegí Mercado Pago o transferencia bancaria, avanzá y usá **Completar con datos de prueba**.
4. Confirmá para ver el resumen, la referencia y el estado del pedido de muestra.

El carrito se conserva en el navegador si el almacenamiento local está habilitado. Los datos de entrega se usan en memoria durante el recorrido. La demo utiliza un catálogo, envíos, precios, cobros y WhatsApp de muestra, sin integraciones activas.
